# Noto · 知微 — 核心流程 E2E 自测清单

> 约 **15 分钟** 跑完一遍，用于演示前验收与发版前回归。  
> 默认账号：`admin` / `admin123`（本地 dev 自动创建）

---

## 环境准备

- [ ] 后端健康：`GET http://localhost:9086/api/v1/health` → `code: 0`
- [ ] 前端可访问：`http://localhost:5173`（或 Docker `8080`）
- [ ] （可选 AI）`GET /api/v1/ai/status` → `enabled: true`

---

## 路径 A：新用户闭环（推荐演示）

> Docker 演示：`.\scripts\demo-up.ps1` → 登录 **admin / admin123** → 已有「周会纪要」「功能导览」与 3 条待办

### 1. 注册与引导

- [ ] 注册新账号 → 自动登录并跳转首页
- [ ] 弹出「从这里开始」引导（三步：写文档 → 提取待办 → 开始执行）
- [ ] 点击「新建第一篇文档」→ 进入笔记编辑页
- [ ] 侧栏「使用引导」可再次打开引导

### 2. 写文档

- [ ] 选择/创建知识库，新建文档并输入正文，例如：

```markdown
# 周会纪要
- [ ] 整理 Q2 目标
- [ ] 周五前提交周报
待办：回复客户邮件
```

- [ ] 自动保存生效（刷新后内容仍在）

### 3. 提取待办（规则，无需 AI）

- [ ] 文档右键或 AI 面板 → **规则提取待办**
- [ ] 预览列表包含上述 3 项
- [ ] 勾选后确认 → 提示创建成功

### 4. 行动看板

- [ ] 首页「今日行动」待办队列出现新待办
- [ ] 拖拽：队列 → **进行中** → **今日完成**
- [ ] 待办中心 `/todos?view=board` 数据一致

### 5. 关联与提醒

- [ ] 新建待办 → **关联文档** 下拉可搜索选择（非手填 ID）
- [ ] 待办设提醒 → 到期后前端轮询出现通知
- [ ] （可选）登录后有逾期待办时，每日一次页内/系统提醒
- [ ] （可选）开启 digest/复盘后，生成完成收到通知
- [ ] （可选）提醒完成后「写复盘进原笔记」

---

## 路径 B：AI 能力（需配置 DashScope Key）

### 6. AI 助手

- [ ] 侧栏 **AI 助手** → 进入即可见底部输入框，无需滚动
- [ ] 选择知识库 + 范围 → 提问 → 流式回答 + 引用文档可点击跳转
- [ ] 历史会话列表可切换、新建、清空

### 7. 编辑页 AI

- [ ] 选中段落 → 浮动工具栏润色/扩写
- [ ] 保存后「写完推一步」提示（可关闭）
- [ ] AI 提取待办 → 审查确认入库

### 8. 全局指令

- [ ] `Ctrl+K` → 搜文档 / 问 AI / 快速办事
- [ ] Cmd+K 选中文档 → 跳转并滚到正文匹配处
- [ ] 跨文档合成 → 生成新笔记草稿

---

## 路径 C：搜索与知识库

- [ ] 全局搜索关键字 → 高亮片段 → 跳转文档并滚到正文匹配处
- [ ] Cmd+K 搜索文档 → 同样滚到匹配段落
- [ ] 知识库树：子文档、拖拽排序、分组浏览
- [ ] 图片上传（MinIO 启用时）→ Markdown 预览正常

## 已知限制（演示时说明）

| 项 | 说明 |
|----|------|
| Redis / RabbitMQ | 未接入；异步索引用进程内线程 |
| 提醒推送 | 浏览器轮询 + 系统通知；无邮件/短信 |
| 周期总结 | 每日 digest / 每周复盘生成后页内 + 后台系统通知 |
| RAG 大库 | 已接入 pgvector（Docker 镜像 `pgvector/pgvector:pg16`）；本地 plain Postgres 回退内存扫描 |
| AI 未启用 | 规则提取、看板、提醒仍可用 |

## 演示脚本（15 分钟口播参考）

1. **1 min** — 登录，展示首页四步看板  
2. **3 min** — 写一篇带 `- [ ]` 的会议纪要，规则提取待办  
3. **3 min** — 看板拖拽推进，设一个提醒  
4. **4 min** — AI 助手问知识库 + 引用跳转（或 Cmd+K 演示）  
5. **2 min** — 搜索定位、关联文档待办  
6. **2 min** — Docker 一键部署 / 路线图阶段八（稳定与体验）
