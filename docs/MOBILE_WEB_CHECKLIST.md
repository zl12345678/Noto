# 移动 Web 验收清单

> 与 [MULTI_PLATFORM.md](./MULTI_PLATFORM.md) §6 对应。  
> **原则**：移动端与桌面 **同一套路由与业务能力**，仅布局/导航适配（`MobileLayout` + `mobile.css`），不拦截 `/ai`、`/drive`、`/shares`。  
> 环境：Chrome 设备模拟 **<768px** 或真机。

## 导航与模块（功能不删减）

- [ ] 底 Tab：首页 / 笔记 / 待办 / 我的
- [ ] 顶栏 **更多**：AI 助手、网盘、我的分享、提醒、首页
- [ ] 我的 → 模块入口：AI / 网盘 / 分享 / 提醒 / 搜索
- [ ] 各模块页面可打开、可返回，无被重定向到首页

## 路径 1：首页

- [ ] 今日行动使用 **完整 `ActionWorkflowBoard`**（含拖拽跨列，横向可滑）
- [ ] 待办状态变更与桌面一致

## 路径 2：笔记

- [ ] 无 workspace 时：知识库 Hub；进入库后：文档树 + 编辑器
- [ ] 阅读 / 编辑切换、AI 侧栏、附件、上下文、分享、提取待办均可用
- [ ] 新建 / 导入 / 分组与桌面一致

## 路径 3：待办

- [ ] 看板视图：进行中 + 队列 + 长期目标（与桌面同一组件）
- [ ] 密度切换、导出 ICS、列表视图、新建/提醒/推迟等

## 路径 4：AI / 网盘 / 分享

- [ ] `/ai` 可对话（SSE）、办事确认流与桌面一致
- [ ] `/drive`、`/shares` 可浏览与操作（小屏可横向滚动）

## 路径 5：提醒 / 搜索 / 个人

- [ ] 提醒列表、系统通知开关
- [ ] 顶栏搜索 → 结果 → 笔记
- [ ] 账号、AI 偏好、自动化规则表单可滚动完成

## 路径 6：回归桌面

- [ ] 宽度 ≥768px → `AppLayout` 三栏
- [ ] 移动端操作的数据与桌面一致

## PWA（可选）

- [ ] `npm run build:prod && npm run preview`：manifest、`PwaInstallHint`（Android）/ iOS 添加快捷方式文案

## 体验差异（允许，非删功能）

- 无左侧全局导航栏、无 `ModuleTabBar`（用 Tab + 更多代替）
- 小屏触控、横向滚动增多；Cmd+K 未做移动端专用入口（可后续加浮动按钮）
