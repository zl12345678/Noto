Reference 0002

Java 开发者 AI 术语速查

这些词不用先学数学。先把它们当成后端工程里的组件、数据结构和调用链。

基础调用

术语人话解释Java 后端类比Noto 代码
LLM 大语言模型，接收文本，生成文本。 一个远程智能服务。 ChatModel, StreamingChatModel
Prompt 发给模型的完整指令，包括角色、规则、资料和用户问题。 请求 DTO + 业务规则 + SQL 条件的组合。 buildAskContext, buildTransformPrompt
Token 模型处理文本的最小片段，近似理解成“字/词片段”。 接口入参和返回内容的计费/长度单位。 sendToken
Streaming 模型边生成边返回，不等完整答案结束。 后端分块响应。 SseEmitter, askStream

RAG 检索

术语人话解释Java 后端类比Noto 代码
Embedding 把文本变成一串数字，用来表示语义。 给文本生成“语义指纹”。 QwenEmbeddingModel
Vector Embedding 生成的数字数组。 float[] 特征字段。 embedding.vector()
Vector search 找语义最相似的文本片段。 不是 where title like，而是按相似度排序。 searchByVectorSimilarity
RAG 先检索资料，再把资料交给模型回答。 先查数据库，再组织业务响应。 NoteRetrievalService
pgvector PostgreSQL 的向量检索扩展。 让数据库支持“按语义相似度 order by”。 PgVectorSupport
HNSW 一种加速向量近邻搜索的索引。 类似给查询建索引，不用每次全表扫。 idx_note_rag_chunk_embedding_hnsw

Agent 和工程守护

术语人话解释Java 后端类比Noto 代码
Agent 让模型决定要调用哪些业务工具完成任务。 自然语言版的业务编排层。 AgentPlanner, AiAgentServiceImpl
Tool call 模型规划出的业务动作，比如搜索文档、创建待办。 调用一个 service 方法。 AgentToolExecutor
Confirmation 写操作先预览，用户确认后执行。 危险操作二次确认。 pending_confirm, confirm
Hallucination 模型编造不存在的信息。 远程服务返回了看似合理但不可信的数据。 KNOWLEDGE_GAPS, references
Audit log 记录 AI 调用发生了什么、是否成功、耗时多少。 业务操作日志/接口调用日志。 recordAudit
