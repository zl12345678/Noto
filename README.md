# Noto · 知微

> 一个面向知识管理与智能辅助场景的个人/团队笔记项目。

Noto · 知微 旨在帮助用户更高效地记录、整理、检索和回顾知识，同时结合 AI 能力与待办提醒，构建一个更智能的知识管理与工作协同平台。

当前仓库处于**项目初始化与脚手架搭建阶段**，已完成基础文档体系、后端工程骨架与部分核心基础组件，后续将逐步推进核心业务功能实现。

## 一、项目背景

在日常学习、工作和团队协作中，用户通常会面临以下问题：

- 笔记分散，难以统一管理
- 搜索效率低，历史内容难以快速找回
- 知识沉淀和复用成本高
- 待办事项和提醒容易遗漏
- 希望借助 AI 提升整理、总结和问答效率

因此，本项目希望提供一个兼顾**笔记管理、知识检索、任务提醒、AI 辅助**的轻量化平台，让知识真正沉淀下来，并能够被高效调用。

## 二、项目定位

本项目当前定位为：

- 个人知识库
- 团队知识协作工具
- AI 辅助笔记与任务管理平台
- 面向 MVP 的可持续演进系统

## 八、如何启动后端

### 1. 准备环境

请确保本地已安装：

- JDK 17 或更高版本
- Maven
- IntelliJ IDEA（推荐）

### 2. 克隆仓库

```bash
git clone https://github.com/zl12345678/Noto.git
cd Noto
```

### 3. 打开后端工程

使用 IntelliJ IDEA 打开 `backend/` 目录。

### 4. 启动项目

在 `backend/` 目录下执行：

```bash
mvn spring-boot:run
```

或者直接运行启动类：

```text
com.noto.zhihui.ZhihuiApplication
```

### 5. 健康检查

启动成功后，可访问健康检查接口：

```text
GET /api/v1/health
```

返回示例：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "status": "UP"
  },
  "traceId": "health-trace-id"
}
```
